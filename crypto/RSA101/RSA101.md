# RSA101

* **Puntos:** 100

## Descripción
> We've received a message we believe is encrypted with RSA, but the primes in the public key could be weak. Find the factors and decipher the message.

* **Exponente público ($e$):** `17`
* **Texto cifrado (ciphertext):** `152293808340616594229073242267037730353433147091103189533666`

## Vulnerabilidades
Al observar los datos del reto y la descripción, se pueden notar las siguientes anomalías que rompen la seguridad de RSA:

1. **Tamaño reducido de $n$:** El módulo $n$ es relativamente pequeño (aproximadamente 60 dígitos / 200 bits). Un módulo de este tamaño no ofrece resistencia contra los algoritmos modernos de factorización de enteros.
2. **Primos débiles (Factorización Directa):** La descripción confirma que los números primos $p$ y $q$ utilizados para generar $n$ ($n = p \times q$) son débiles. Al ser un número pequeño, $n$ puede ser fácilmente factorizado utilizando bases de datos públicas de factores (como Factordb) o algoritmos locales como Fowler o la curva elíptica (ECM).
3. **Cálculo de la clave privada ($d$):** Una vez obtenidos los factores $p$ y $q$, la función phi de Euler $\phi(n) = (p-1)(q-1)$ deja de ser secreta, lo que permite calcular el exponente privado $d$ mediante el inverso multiplicativo modular:
   $$d \equiv e^{-1} \pmod{\phi(n)}$$

---

## Resolucion
Para resolver este reto, los pasos a seguir serían:

1. Inputar el valor de $n$ en una herramienta de factorización (ej. `factordb.com`) o usar herramientas locales como `sagemath` o `ysafu` para romper $n$ en sus dos componentes primos $p$ y $q$.
2. Utilizar los valores de $p$ y $q$ encontrados para calcular $\phi(n) = (p-1) \times (q-1)$.
3. Calcular el exponente de descifrado privado $d$ utilizando el inverso modular de $e$ respecto a $\phi(n)$.
4. Descifrar el mensaje utilizando la fórmula estándar de RSA: $m = c^d \pmod n$.
5. Convertir el entero largo resultante ($m$) a texto plano (ASCII / bytes) para revelar la flag.
